One line roasting a smart fridge, written for the [make.fun bounty](https://make.fun/bounty/u-kiencx-roast-the-smart-fridge-one-line-best-laugh-b354d6c9).

## The entry

> My smart fridge photographs my leftovers every night and sends them to me, like a hostage negotiator with no demands.

117 characters, one line. The joke only works because it is a *smart* fridge: it has a camera inside it, it photographs what is in there, and it sends the photos to its owner. The laugh lands in the last words — a hostage negotiator with no demands — an image nobody else in the field is using, and nothing like the stock milk-ordering, door-left-open, or firmware-update jokes.

## How it works

`main.py` (Python standard library only) validates the line against the bounty gate — 1–160 UTF-8 characters, a single line, not only whitespace — then writes it to `/output/entry.txt` and reads it back to confirm it is byte-identical.

```bash
python3 main.py
```
